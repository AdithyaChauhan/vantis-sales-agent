# Prompts

Every LLM prompt lives here as a `.md` file. Code loads them with `load_prompt(name)` (`backend/app/core/prompts.py`); no prompt text is written in code. Each file holds only the prompt text.

| File | Used by | Purpose |
|---|---|---|
| `system_prompt.md` | The agent node (`app/agent/graph.py`), as the system message | Role, tone, KB-only rule, citation rule, at most one follow-up question, the never-invent list (KB Section 16), off-topic redirect, KB and user text treated as data. T8a: tool policy (`search_knowledge_base`, `check_service_area`), how to word listed and unverified cities, list every offering, short replies, no claimed actions. T8b adds the lead tools |
| `lead_qualification_prompt.md` | `app/leads/reason.py`, sent to the fast model | Writes the one-sentence `reason` for a lead's status from the score breakdown only (status, score, rule labels with points, caps, city). It never sees a name, phone, email or money amount. It must not mention prices, savings, subsidies, financing, EMIs, guarantees or dates (KB Section 16). Code checks the reply and uses a template sentence when it is empty, too long, more than one sentence, names another status or touches a forbidden topic. Placeholders: `{status}`, `{score}`, `{city}`, `{factors}`, `{caps}` |
| `rag_prompt.md` | The agent node, wrapping the customer's latest message | Shows the retrieved chunks inside `<context>`, each starting with its label `[KB Section N: Title]`; sets the citation format; says what to do when the context does not cover the question. Placeholders: `{context}`, `{question}` (filled with `str.replace`, context first) |
| `lead_extraction_prompt.md` | The understand node (`app/agent/understand.py`), sent to the fast model with structured output | Intents (question, buying interest, greeting, reply to the assistant, thanks or bye, existing-customer issue, off-topic), a standalone `search_query` in the KB's own words, and the lead details the customer stated (`LeadData` field names and descriptions). Gets the KB section titles and the KB Section 8 summary chunk from the database, and the last 6 messages. Placeholders: `{section_titles}`, `{catalog}`, `{history}`, `{message}` (filled last) |
